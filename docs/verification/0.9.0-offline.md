# 0.9.0 development verification

Date: 2026-11-05. Source base: `f322938` (0.8.1 screen-source-edit integration).
Work branch: `codex/carrier-recovery-settings`.

## Implemented scope

- Optional named C carrier/settings APIs, plus equivalent independent Lua calls.
- Bounded next-tick dock requests and owner-scoped results; lazy four-hook
  recovery transaction, parked/bay/session/thread guards and native budgets.
- One window per continuous recall, abort loop breaker, XMM preservation,
  callback-error/removal cancellation and process-latched native-fault refusal.
- Typed, bounded, atomic settings persistence without Lua OS/filesystem access.
- C API 8 (296-byte x86 prefix), framework API 1, Lua API 2 and earlier screen
  extension behavior preserved by the existing regression fixtures.

including capability classification, PE exports, distribution/source separation
and the unchanged package/release checks. `git diff --check` is clean.

Symlink creation is conditional on the Windows host. The leaf/ancestor symlink
fixture branches did not execute on this local host; do not count them as fresh
local reparse-point acceptance. Hardlink and locked-file branches did execute.

`build/unified/test-results.json`. The committed-candidate build identifies its
own source commit and cleanliness; these JSON records are the artifact identity.
